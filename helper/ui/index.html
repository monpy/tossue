GitHub CLI Support

Tossue Helper は `gh` コマンドを使って Issue を作成します。見つからない場合は次を確認してください。

  • GitHub CLI をインストールする
  • Terminal で which gh が通ることを確認する
  • Tauri app を起動し直して PATH を再読込する

How It Works

  • 1. このアプリが 127.0.0.1:47321 で待ち受けます。
  • 2. 拡張が health / GitHub status / repository list を確認します。
  • 3. 接続できた場合だけ Issue 作成を helper に委譲します。
  • 4. 接続できない場合は拡張側で Copy Markdown を案内します。

GitHub CLI

この helper から `gh auth status` を確認できます。ログインは Terminal を開いて gh auth login --web を実行します。
