GitHub CLI Support

Tossue Helper は `gh` コマンドを使って Issue を作成します。見つからない場合は次を確認してください。

  • GitHub CLI をインストールする
  • Terminal で which gh が通ることを確認する
  • Tauri app を起動し直して PATH を再読込する

How It Works

  • 1. このアプリが 127.0.0.1:47321 で待ち受けます。
  • 2. 拡張が health / GitHub status / repository list を確認します。
  • 3. 接続できた場合だけ Issue 作成を helper に委譲します。
  • 4. 接続できない場合は拡張側で Copy Markdown を案内します。

GitHub CLI

この helper から `gh auth status` を確認できます。ログインは Terminal を開いて gh auth login --web を実行します。

Upload Script Settings

画像・動画をアップロードするカスタムスクリプトを設定します。スクリプトは stdout に URL を出力してください。

Input (Environment Variables)

TOSSUE_FILE_PATH    Path to the file to upload
TOSSUE_FILENAME     Original filename (e.g. screenshot-1.png)
TOSSUE_MIME_TYPE    MIME type (e.g. image/png, video/webm)

Expected Output

Print the uploaded file URL to stdout.
Only the first line is used.

Example: https://example.com/uploads/image.png

Issue Body Preview

The URL will be embedded in the issue body as:

## Attachments
![screenshot-1.png](https://example.com/xxx.png)
[recording-1.webm](https://example.com/xxx.webm)
