Privacy Policy

Last updated: March 17, 2026

No Data Collection

Tossue does not collect, store, or transmit any user data to our servers. We do not use analytics, tracking, or any third-party services.

Local Processing Only

All data captured by Tossue (console logs, network errors, screenshots, etc.) is processed and stored locally on your device. This data is only sent to GitHub when you explicitly create an issue, using your own GitHub credentials.

GitHub Integration

When you connect your GitHub account, authentication is handled through GitHub's OAuth. We use a minimal Cloudflare Worker to complete the OAuth handshake, which does not store any user data.

Use at Your Own Risk

Tossue is provided "as is" without warranty of any kind. You are responsible for:

  • Reviewing captured data before submitting issues
  • Ensuring no sensitive information is included in bug reports
  • Managing your GitHub account access

By using Tossue, you accept full responsibility for how you use the extension and the data you choose to share.
