Privacy Policy

Last updated: March 17, 2026

Overview

Tossue is a Chrome extension and optional desktop helper app that collects debugging context from web pages to help create structured GitHub issues. We are committed to protecting your privacy and being transparent about what data is collected and how it is used.

Data Collection

Tossue collects the following types of data only when you actively use the extension to capture debugging context:

  • Console logs and errors - JavaScript errors, warnings, and logs from the browser console
  • Network errors - Failed HTTP requests and their details
  • Component information - React, Vue, Nuxt, or Next.js component hierarchy on the current page
  • Page events - User interactions and page navigation events
  • Screenshots and recordings - Visual captures you explicitly take
  • Page URL and browser info - Current URL and basic browser/viewport information

Data Storage

All collected data is stored locally on your device using Chrome's built-in storage APIs. Your data is never sent to our servers.

  • Debugging context is stored temporarily in browser storage
  • GitHub OAuth tokens are stored locally in Chrome's secure storage
  • Settings and preferences are stored locally

Data Sharing

Tossue only sends data to external services in two cases:

  • GitHub API - When you create an issue, the collected debugging context is sent to GitHub's API to create the issue in your selected repository. This is done using your own GitHub account credentials.
  • GitHub OAuth - During sign-in, we use a Cloudflare Worker to complete the OAuth flow. This worker only handles the authentication handshake and does not store any user data.

We do not use any analytics, tracking, or advertising services. We do not collect or store your data on our servers.

Your Control

You have full control over your data:

  • Choose what to capture - customize capture settings in the extension
  • Review before sending - all collected data is visible before creating an issue
  • Clear data anytime - use Chrome's extension storage settings to clear stored data
  • Revoke access - disconnect your GitHub account at any time
  • Uninstall - removing the extension deletes all locally stored data

Permissions

Tossue requires certain Chrome permissions to function. Here's why each is needed:

  • activeTab - Access the current tab to capture debugging context
  • debugger - Capture network requests and console logs
  • downloads - Save screenshots and recordings locally
  • identity - Handle GitHub OAuth authentication
  • scripting - Inject scripts to detect components
  • storage - Store settings and captured data locally
  • tabs - Access tab information for context
  • sidePanel - Display the extension's side panel UI
